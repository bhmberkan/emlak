# EMLAK OTOMASYON PROJESİ

**Emlak Otomasyon Projesi**, emlak ofislerinin mülk yönetimini kolaylaştırmak amacıyla geliştirilmiş bir sistemdir. Kullanıcı dostu arayüzü ile emlak sektörüne yönelik bir çözüm sunmaktadır.

## 📌 Proje Özellikleri

- **Emlak ilan yönetimi** (Ekleme, güncelleme, silme)
- **Veritabanı tabanlı mülk takibi**
- **Kolay arayüz ve kullanıcı dostu deneyim**

## 🚀 Kullanılan Teknolojiler

- **C# & ASP.NET**
- **MSSQL Veritabanı**

## ⚙️ Kurulum

1. **Projeyi klonlayın:**
   ```sh
   git clone https://github.com/bhmberkan/emlak.git
   ```
2. **Veritabanını oluşturun:**
   - MSSQL kullanarak gerekli tabloları oluşturun.
   - `appsettings.json` veya `web.config` dosyasında bağlantı dizesini güncelleyin.
3. **Projeyi çalıştırın:**
   - Visual Studio veya bir IDE kullanarak projeyi açın.
   - `IIS Express` veya `Kendi Web Sunucunuz` ile başlatın.
